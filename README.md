# 📡 HCIC Training

A collection of Jupyter Notebook study notes organized by topic to help prepare for the **Hwa Chong Info-communications Challenge (HCIC)** — an annual national competition organized by Hwa Chong Institution for Primary 6 students in Singapore.

---

## 📚 Topics Covered

| Notebook | Description |
|---|---|
| `Part1_Variables_Assignment_Operators.ipynb` | Variables, assignment, and arithmetic/logical operators |
| `Part2_Data_Types_and_Type_Conversion.ipynb` | Integers, floats, booleans, and converting between types |
| `Part3_Strings_Indexing_Slicing_Operations.ipynb` | String methods, indexing, slicing, and common operations |
| `Part4_Conditionals.ipynb` | `if`, `elif`, `else` statements and boolean logic |
| `Part5_Loops.ipynb` | `for` and `while` loops, iteration, and loop control |
| `Part6_Lists_and_Tuples.ipynb` | Creating, indexing, and manipulating lists and tuples |
| `Part7_Functions.ipynb` | Defining functions, parameters, return values, and scope |

## 🏆 About the HCIC

The **Hwa Chong Info-communications Challenge (HCIC)** is an annual competition that aims to spark interest in info-communications among primary school students. It tests participants on:

- **Programming Logic** — Computational thinking and problem-solving
- **Python Programming** — Syntax, data structures, and algorithms
- **Robotics Knowledge** — Concepts related to robotics and automation

Awards are given at **Platinum, Gold, Silver, and Bronze** tiers, with Platinum going to the top ~1.5% of participants. Strong results can support **DSA (Direct School Admission)** applications to secondary schools.

For official competition details, visit the [HCIC website](https://sites.google.com/hci.edu.sg/hcic/home).
